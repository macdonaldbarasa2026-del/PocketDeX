The embedded flavor does not package Winlator's wincomponents/*.tzst archives,
which contain Microsoft DirectX and Visual C++ redistributable files, and does
not package its SONiVOX soundfont. New containers default those optional
components off. Users may import files they are licensed to use through the
file picker. Wine's own compatibility fonts are part of Wine, not Microsoft
Windows font files.
